# Media Categorizer 4.3

V4.3 добавляет масштабирование фото и видео и меняет поведение звука по умолчанию.

## Масштаб

В верхней панели появился блок **Масштаб**:

- `−` — уменьшить масштаб на 10%;
- слайдер — диапазон от 25% до 400%;
- `+` — увеличить масштаб на 10%;
- кнопка с текущим значением (`100%`, `150%` и т. п.) — сбросить к 100%.

Горячие клавиши:

- `Ctrl++` / `Ctrl+=` — увеличить;
- `Ctrl+-` — уменьшить;
- `Ctrl+0` — вернуть 100%.

### Что означает 100%

В этой программе 100% — не физический размер пикселей файла. Это режим **Fit to View**: фото или видео максимально вписывается в свободную область просмотра, сохраняя исходные пропорции и не заходя на верхние панели, категории и плеер.

Поэтому даже файл небольшого разрешения при 100% увеличивается до максимально доступного размера. Вертикальные и горизонтальные файлы сохраняют правильное соотношение сторон.

При увеличении выше 100% медиа увеличивается относительно этого вписанного размера. Область просмотра остаётся фиксированной, поэтому панели интерфейса не раздвигаются.

## Звук

Каждый запуск V4.3 начинается со **включённым звуком**, даже если в предыдущей версии был сохранён режим mute. В текущем запуске звук по-прежнему можно отключить обычной кнопкой.

## Сохранено из V4.2

- исправленная ориентация видео;
- нативный `QVideoWidget` для более плавного воспроизведения тяжёлых роликов;
- скорость видео 1× при запуске;
- скрываемые миниатюры и параметры файла;
- плеер непосредственно под видео;
- боковые стрелки навигации;
- категории, действия, шаблоны имён и горячие клавиши;
- поиск точных и визуально похожих дубликатов;
- фоновые копирования/перемещения;
- журнал операций.

## Запуск

Требуется Python 3.11+:

```bat
python -m pip install -r requirements_v4_3.txt
python media_categorizer_v4_3.py
```

Либо запустите `run_v4_3.bat`.

## Сборка EXE

Запустите `build_v4_3_exe.bat`. После успешной сборки:

`dist\MediaCategorizer4_3.exe`
