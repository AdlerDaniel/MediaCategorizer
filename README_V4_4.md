# Media Categorizer 4.4

Версия 4.4 исправляет использование свободной области при показе фото и сохраняет масштабирование V4.3 для фото и видео.

## Главное исправление

В V4.3 фотографии показывались через QLabel с заранее масштабированным QPixmap. В некоторых размерах окна фактическая геометрия QLabel/пиксмапа могла оставаться меньше доступного viewer-пространства, поэтому вокруг изображения появлялись большие пустые зоны даже при 100–150%.

В V4.4 фотографии рисуются отдельным `ImageCanvas`, который при каждом изменении размера использует фактический текущий размер всей области просмотра.

- **100%** = максимально крупное изображение, полностью помещающееся в свободную область.
- На ограничивающей оси изображение упирается в границу viewer-а.
- Пропорции сохраняются.
- Маленькие исходные изображения также увеличиваются до размера viewer-а.
- Значения выше 100% увеличивают изображение относительно fit-to-view и обрезаются границами области, не раздвигая интерфейс.
- Панели сверху, категории снизу, стрелки, миниатюры и параметры файла не перекрываются медиа.

Видео продолжает использовать нативный `QVideoWidget` из V4.2/4.3 и масштабируется относительно всей свободной области по тому же принципу fit-to-view.

## Горячие клавиши масштаба

- `Ctrl++` / `Ctrl+=` — увеличить
- `Ctrl+-` — уменьшить
- `Ctrl+0` — вернуть 100%
