# Media Categorizer V4

V4 сохраняет функции V3 и добавляет инструменты для работы с большими коллекциями медиа.

## Новое в V4

### 1. Лента миниатюр

Под текущим медиа показывается горизонтальная лента до 25 соседних файлов: 12 предыдущих, текущий и 12 следующих.

- Нажатие по миниатюре сразу открывает этот файл.
- Фото получают реальные миниатюры в фоне.
- Для видео сначала показывается значок видео, а после декодирования первого кадра он заменяется реальным превью.
- Текущий файл автоматически центрируется в ленте.

### 2. Стрелки навигации

Кнопки `Назад` и `Пропустить` убраны из верхней панели как основной способ навигации.

Слева и справа от медиа теперь находятся большие кнопки:

- `❮` — предыдущий файл;
- `❯` — следующий файл.

Клавиши `←` и `→` на клавиатуре работают как раньше.

### 3. Поиск точных дубликатов

Кнопка **Дубликаты** открывает отдельное окно сканирования.

Точные дубликаты:

1. сначала группируются по размеру;
2. только кандидаты одинакового размера сравниваются по SHA-256;
3. в результат попадают файлы с полностью одинаковым содержимым.

Это работает и для фото, и для видео.

### 4. Поиск визуально похожих фото

В том же окне программа ищет похожие изображения через 64-битный perceptual dHash.

- Допускаются изменения размера и повторное сжатие.
- Используется порог Hamming distance 8.
- Для больших папок применяется BK-tree, поэтому не требуется сравнивать каждое фото с каждым.
- Поиск выполняется в фоне.

Результаты разделяются на `Точный` и `Похожие фото`.

Из выбранной группы можно сразу перейти к первому файлу в основном окне.

### 5. Панель параметров файла

Справа от медиа показываются:

- тип файла;
- размер файла;
- разрешение;
- длительность;
- FPS;
- видеокодек;
- формат;
- время создания;
- время изменения.

Для видео часть параметров появляется после того, как Qt прочитает metadata файла.

### 6. Фоновая очередь копирования и перемещения

Действия категорий `Копировать`, `Переместить`, `Переименовать + копировать` и `Переименовать + переместить` больше не должны блокировать просмотр больших файлов.

После нажатия категории:

1. операция добавляется в очередь;
2. следующий файл открывается сразу;
3. копирование/перемещение выполняется в фоне;
4. снизу отображаются текущая операция, длина очереди и прогресс;
5. журнал получает запись о постановке в очередь и о результате.

Дисковые операции выполняются по одной, чтобы несколько больших видео одновременно не забивали диск.

Если перемещение завершилось ошибкой, исходный файл возвращается в список обработки.

Программа не закрывается, пока очередь не закончена, чтобы не оставить частично скопированный файл.

### 7. Что сохранено из V3

- исправление EXIF/rotation для фото и видео;
- ручной поворот отображения;
- полноэкранный режим;
- timeline видео;
- ±5 секунд;
- изменение скорости;
- покадровый шаг;
- несколько тегов;
- горячие клавиши категорий;
- шаблоны переименования;
- действия категорий;
- защита от повторных префиксов;
- Undo;
- журнал CSV;
- предзагрузка изображений и видео;
- сохранение настроек и последней папки.

## Запуск

Нужен Python 3.11+.

```bat
python -m pip install -r requirements_v4.txt
python media_categorizer_v4.py
```

Или запустите `run_v4.bat` после установки зависимостей.

## Сборка EXE

Запустите:

`build_v4_exe.bat`

Готовый файл появится здесь:

`dist\MediaCategorizer4.exe`

## Горячие клавиши

- `←` / `→` — предыдущий / следующий файл;
- `Space` — Play/Pause;
- `Ctrl+←` / `Ctrl+→` — ±5 секунд;
- `Alt+←` / `Alt+→` — кадр назад / вперёд;
- `Ctrl+Z` — отменить последнюю завершённую файловую операцию;
- `Enter` — применить несколько выбранных тегов;
- `F11` — полноэкранный режим;
- `Esc` — выход из полноэкранного режима.

## Примечание о фоновых операциях и Undo

Копирование/перемещение становится доступно для Undo только после фактического завершения фоновой операции. Пока файл находится в очереди или копируется, действие ещё не помещается в стек Undo.
