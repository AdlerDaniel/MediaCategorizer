# Media Categorizer 4.5

Версия 4.5 исправляет проблему V4.3/V4.4, когда фото или видео визуально занимали лишь маленький прямоугольник в центре, хотя свободная область окна была значительно больше.

## Главное исправление V4.5

В старой схеме `ImageCanvas` и `VideoCanvas` получали геометрию вручную. На некоторых конфигурациях Windows/Qt фактический canvas оставался близок к старому минимальному размеру (примерно 400×260), поэтому даже 300–400% считались относительно маленькой области.

В V4.5 центральная область перестроена:

- `media_stack` теперь имеет `Expanding` по ширине и высоте;
- минимальный размер 400×260 удалён;
- фото помещено в настоящий `QStackedLayout`, который растягивает его на всю доступную область;
- видео получило отдельный `video_host`, который также растягивается на весь viewport;
- ручной `setGeometry()` для фото удалён;
- видео пересчитывает размер уже после того, как layout закончил изменение геометрии.

## Масштаб

- 100% = максимально вписать медиа в реальную свободную область между панелью инструментов и нижними элементами интерфейса.
- 150% = 1.5× от этого вписанного размера.
- 200% = 2×.
- 25–400% доступны слайдером и кнопками.
- Ctrl+0 возвращает 100%.

При 100% одна из сторон файла упирается в соответствующую границу свободной области, если это позволяет соотношение сторон. Пропорции не искажаются.

## Остальное

Сохранены функции V4.4:

- исправление ориентации видео;
- нативный видеовывод Qt для более плавного 4K/60 FPS;
- звук включён по умолчанию;
- скорость видео 1× при запуске;
- скрываемые миниатюры и параметры файла;
- стрелки навигации;
- категории/действия, журнал и поиск дубликатов;
- фоновые операции без видимой панели.

## Запуск

```bat
run_v4_5.bat
```

Или:

```bash
pip install -r requirements_v4_5.txt
python media_categorizer_v4_5.py
```

## Сборка EXE

Запустите:

```bat
build_v4_5_exe.bat
```

После сборки файл будет находиться в `dist\MediaCategorizer4_5.exe`.
