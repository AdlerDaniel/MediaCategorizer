# Media Categorizer

Программа для просмотра, категоризации, переименования, копирования и перемещения фото/видео. Текущий выпуск — 6.2.1. README_V4*.md сохранены как история предыдущих выпусков.

## Исправление в 6.2.1

Исправлен сбой перезапуска после обновления: «Security validation failure: parent process has different executable!». Новый процесс больше не наследует служебное окружение старого EXE. Установщик также готовит отдельное окружение при запуске приложения, в том числе для обновлений из старых версий. Перед заменой файлов ожидается завершение обоих процессов однофайловой сборки. Проверки безопасности PyInstaller и SHA-256 остаются включены.

Регрессионная проверка tools/frozen_restart_probe.py собирается PyInstaller в режиме --onefile --console: без исправления она воспроизводит исходное сообщение, с независимым окружением подтверждает успешный запуск. tools/verify_update_handoff.py дополнительно проверяет обновление с унаследованным окружением старого клиента.

- Выбор оформления кнопкой солнца/луны справа вверху: тёмно-синяя, тёмно-зелёная, тёмно-коричневая, тёмно-жёлтая, тёмно-фиолетовая и светлая темы. Выбор сохраняется после закрытия программы.

- Диалоги выбора файлов и цвета также используют оформление программы. На Windows 11 цвета применяются и к заголовкам окон; на Windows 10 используется соответствующий светлый или тёмный заголовок.
- Категории без собственного цвета следуют теме. В настройках категории можно выбрать «Цвет темы» или сохранить индивидуальный цвет.

## Новое в 6.1

- Новая иконка приложения, EXE и установщика из предоставленного изображения.
- При запуске программа проверяет GitHub Releases в фоне. Если версия новее, показывает описание выпуска и кнопки «Обновить» и «Позже». При отсутствии интернета запуск продолжается без уведомлений об ошибке.

- Экспорт видео: исходное разрешение, 720p или 1080p; исходная частота кадров либо 24/25/30/60 fps; три уровня качества и приблизительный размер. По умолчанию — 720p, 30 fps.

- Категории: цвет, иконка, клавиша и подпись действия, перетаскивание кнопок для изменения порядка, сохранение и загрузка именованных наборов в настройках категорий.
- Библиотека (кнопка с изображениями рядом с открытием файла): поиск по имени/пути, фильтры фото/видео/обработанные, сортировка и вложенные папки. Длительности считываются в фоне при выборе соответствующей сортировки. Обработанные определяются по успешным записям журнала.
- Выбор нескольких строк через Ctrl/Shift → «Обработать выбранные»: категории, копирование, перемещение, переименование, отражение/поворот фото, преобразование видео. Сначала подготовьте и проверьте список, затем запустите очередь. Кнопка остановки отменяет оставшиеся операции; текущее копирование/перемещение завершается.
- «Настройки → О программе и обновления»: версия, описание выпуска, ручная проверка GitHub Releases, загрузка с проверкой SHA-256 и запуск Update после закрытия программы.

Фото- и видеопреобразования заменяют исходники. Пакетная обработка не создаёт резервных копий и не поддерживает общую отмену после сохранения.

Скачать установщик и обновление: [GitHub Releases](https://github.com/AdlerDaniel/MediaCategorizer/releases/latest). Для скачивания нужен интернет; запуск уже скачанного Setup/Update работает автономно.

## Запуск

Для Windows 10/11 x64: запустите `dist/MediaCategorizer-Setup-6.2.1.exe`. Python отдельно не нужен. Установка выполняется для текущего пользователя, по умолчанию в `%LOCALAPPDATA%/Programs/MediaCategorizer`; программа появляется в меню «Пуск» и списке установленных приложений Windows. Ярлык рабочего стола можно выбрать в мастере.

Для следующих выпусков используйте `MediaCategorizer-Update-<версия>.exe`: закройте программу и запустите обновление. Оно находит установленную копию и заменяет файлы в той же папке, сохраняя настройки, журнал и ярлыки. Отдельная вторая копия не создаётся. Обновление без первой установки, при работающей программе или поверх более новой версии блокируется. Это полный автономный пакет обновления; подключение к интернету не требуется.

Если раньше использовалась переносимая версия 4.5, сначала запустите Setup: старый EXE не был зарегистрирован как установленная программа. Настройки из прежней папки APPDATA подхватятся автоматически.

Переносимая сборка: `dist/MediaCategorizer.exe`.

Из исходников: Python 3.11+; проверено с Python 3.14.5.

```bat
python -m pip install -r requirements_v4_5.txt
python media_categorizer_v4_5.py
```

После установки зависимостей можно использовать `run_v4_5.bat`.

## Видеоредактор

Кнопка «Редактировать» теперь доступна и для видео. В отдельном окне задайте начало и конец отрезка в секундах или кнопками «Начало здесь»/«Конец здесь» по позиции плеера. Громкость: 0–200%, где 100% — исходный уровень, 0% — тишина. В предпросмотре предусмотрен запас громкости для слышимого усиления.

По умолчанию сохранение перекодирует выбранный отрезок в 30 fps: 1280×720 для горизонтальных и квадратных роликов, 720×1280 для вертикальных. Пропорции сохраняются, при необходимости добавляются поля. Имя, путь и контейнер исходника сохраняются; видео и звук перекодируются совместимыми с контейнером кодеками. Сохраняются все звуковые дорожки, громкость меняется у каждой; дополнительные видеодорожки, субтитры и вложения в этой версии не переносятся.

Экспорт выполняется в фоне, показывает прогресс и допускает отмену. Только успешно закодированный и проверенный результат заменяет оригинал. До замены отмена, ошибка записи или изменение исходника другой программой оставляют оригинал на месте. Полное восстановление исходного качества после сохранения не предусмотрено.

FFmpeg 8.1.2 входит в установку; подключение к интернету для монтажа не требуется. Для переносимого запуска рядом с MediaCategorizer.exe нужна папка ffmpeg из dist. Для сборки из исходников выполните python tools/prepare_ffmpeg.py --source «папка ffmpeg-8.1.2-full_build»; build_release.py автоматически использует уже установленную подходящую сборку WinGet. Лицензия и ссылки на исходники FFmpeg находятся в ffmpeg/LICENSE.txt и NOTICE.txt.

## Редактор фото

Откройте фотографию и нажмите «Редактировать» в панели просмотра. Откроется отдельное окно в текущей теме. Доступны отражение по горизонтали/вертикали, выделение прямоугольника мышью, обрезка и сброс всех правок. Рамка обрезки соответствует пикселям оригинала, независимо от размера окна. «Сохранить» также применяет текущую рамку, если вы ещё не нажали «Обрезать выделенное».

Сохранение заменяет исходное фото в том же формате и по тому же пути, без отдельной копии. Сначала кодируется временный файл; оригинал заменяется только после успешной записи. Изменённый другой программой или занятый фоновой операцией файл защищён от перезаписи редактором. При закрытии с несохранёнными правками есть выбор вернуться или отбросить их.

После сохранения правки нельзя отменить через общее Ctrl+Z: оно относится к действиям категоризации. JPEG/WebP перекодируются; метаданные EXIF/IPTC не гарантируется сохранить. Анимация, многостраничные файлы и форматы без доступного кодировщика не редактируются, чтобы не потерять кадры/страницы.

## Безопасность файлов

- Копирование выполняется в уникальный временный файл рядом с назначением. Окончательное имя присваивается после полной записи, без перезаписи существующего файла. При ошибке удаляется только временный файл данной операции.
- Перемещение внутри одного диска остаётся быстрым переименованием. Между дисками сначала создаётся полная копия, затем удаляется источник. Если удалить источник не удалось, сохраняются оба файла и показывается ошибка с путями.
- Источник и назначение резервируются на время ожидания и выполнения операции. Повторные действия через кнопки и горячие клавиши блокируются. Undo недоступен, когда затрагивает занятый файл; независимые операции отменять можно. Просмотр и навигация остаются доступны.
- Колесо мыши над фото/видео меняет масштаб с привязкой к курсору. При увеличении выше 100% зажмите левую кнопку и перемещайте медиа. Перемещение ограничено краями. По оси, где медиа меньше области, оно остаётся по центру.
- Слайдер и кнопки масштаба сохранены. 100% означает вписывание. Ctrl+0 возвращает 100% и центрирует медиа. При переходе к другому файлу смещение сбрасывается.
- Логика файловых операций, настроек, имён и просмотра вынесена в отдельные модули. Добавлены автоматические тесты, версии зависимостей закреплены.

## Проверка и сборка

```bat
python -m unittest discover -s tests -v
python -m pip install -r requirements-build.txt
python tools/prepare_release.py
python tools/build_exe.py
```

Для полного релиза установите Inno Setup 6.7+ с https://jrsoftware.org/isdl.php и запустите `build_release.bat` (или `python tools/build_release.py --iscc "путь/ISCC.exe"`). Для нового выпуска измените APP_VERSION в constants.py; версия EXE и обоих пакетов формируется из неё. AppId и путь настроек менять нельзя. Установочные EXE пока не имеют цифровой подписи издателя.

`python tools/verify_installer.py` проверяет цикл установки/обновления/удаления во временной папке, сохранность настроек и журнала, запуск установленного EXE и блокировки обновления. Запускайте под отдельным пользователем Windows без установленной Media Categorizer; сценарий отказывается трогать существующую установку.

Также доступны `run_tests.bat` и `build_v4_5_exe.bat`. Сценарий сборки запускает тесты перед упаковкой. tools/build_exe.py ограничивает PATH каталогами Python и Windows, чтобы не включать несовместимые DLL от сторонних программ. GUI-тесты используют offscreen-платформу Qt и временную папку настроек.

Визуальная проверка на Windows (открывает тестовое окно на несколько секунд):

```bat
set QT_QPA_PLATFORM=windows
python tools/verify_ui.py
```

Результаты сохраняются в `build/qa/`. QWidget.grab не захватывает нативную видеоповерхность Qt; декодированный кадр сохраняется отдельно. Проверка также подтверждает декодирование видео, изменение масштаба колесом и перемещение через события нативного QVideoWindow.

Проверка готовой EXE: `powershell -NoProfile -ExecutionPolicy Bypass -File tools/verify_exe.ps1`. Сценарий запускает приложение скрыто, проверяет создание окна, штатное закрытие и сохранение настроек во временной папке.

Git хранит исходники и инструкции. build/, dist/, кэши Python и виртуальные окружения исключены. Старая EXE-сборка перед первым обновлением сохранена в `dist/archive/MediaCategorizer4_5-original.exe`.

## Текущие ограничения

- Обычное открытие папки читает её верхний уровень; для вложенных папок используйте переключатель в библиотеке.
- Позиция обработки и очередь не восстанавливаются после перезапуска.
- Закрытие программы и смена папки блокируются до завершения очереди.
- При аварийном завершении может остаться временный .mediacategorizer-*.part. Такой файл не считается готовой копией.
- Аппаратное декодирование зависит от кодека, Qt и драйвера видеокарты.
