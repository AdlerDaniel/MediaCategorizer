# Media Categorizer 4.2

V4.2 исправляет две проблемы V4.1: неправильную ориентацию части видео и сильные лаги на тяжёлых роликах.

## Главное изменение видеодвижка

В V4.1 каждый отображаемый кадр видео проходил через Python:

`QVideoFrame -> QImage -> поворот -> масштабирование -> QPainter`

Для 4K, 60 FPS, HEVC/H.265 и роликов с высоким битрейтом это создавало большую нагрузку на CPU и лишние копии больших кадров.

В V4.2 активное видео выводится напрямую через нативный `QVideoWidget` Qt. Pixel buffer больше не превращается в QImage на каждом кадре. QImage создаётся только один раз, когда программе нужно получить миниатюру.

Это позволяет Qt использовать штатный видеорендеринг и доступное аппаратное ускорение декодирования/вывода.

## Исправление ориентации видео

V4.2 учитывает три источника ориентации:

1. rotation в `QVideoFrameFormat`;
2. presentation rotation самого `QVideoFrame`;
3. `QMediaMetaData.Orientation` — дополнительный fallback для телефонных MP4/MOV, где угол записан только в metadata контейнера.

Если кадр уже содержит rotation, metadata повторно не применяется, чтобы не возникало двойного поворота.

Кнопки `↺ Вид` и `↻ Вид` сохранены. Ручной поворот меняет presentation metadata кадра и не перекодирует исходное видео.

## Оптимизация тяжёлых видео

- Убрано преобразование каждого кадра в QImage.
- Активное видео идёт через нативную видеоповерхность Qt.
- Миниатюра создаётся максимум один раз на файл.
- Вместо двух одновременно подготавливаемых следующих видео используется только одно.
- Предзагрузка следующего видео запускается с задержкой, а не одновременно со стартом текущего.
- Для видео примерно 3 Мп и выше (например 2560×1440/4K) параллельная видеопредзагрузка отключается.
- Для роликов около 50 FPS и выше параллельная видеопредзагрузка также отключается.

Это сделано специально, чтобы текущий 4K/60fps ролик не конкурировал за декодер/GPU с будущими файлами.

## Скорость воспроизведения

Как и в V4.1, каждый запуск программы начинается с `1×`.

## Установка

Требуется Python 3.11+.

```bat
python -m pip install -r requirements_v4_2.txt
python media_categorizer_v4_2.py
```

Или запустите `run_v4_2.bat`.

## Сборка EXE

Запустите:

`build_v4_2_exe.bat`

Готовый файл появится в `dist/MediaCategorizer4_2.exe`.

## Примечание по производительности

Фактическое аппаратное декодирование зависит от видеокарты, драйвера, кодека и профиля конкретного видео. V4.2 убирает главное программное узкое место V4.1 — полную обработку каждого кадра в Python — но видео с неподдерживаемым аппаратно кодеком всё равно может декодироваться процессором.
