# Media Categorizer 4.1

Промежуточное обновление V4 с изменениями интерфейса и видеоплеера по итогам тестирования.

## Что изменено в 4.1

### Миниатюры скрыты по умолчанию
В верхней панели инструментов появилась кнопка **«Миниатюры ▸»**.

- При запуске карусель закрыта.
- Нажатие открывает ленту миниатюр.
- Повторное нажатие скрывает её.
- Пока лента закрыта, программа не тратит время на её постоянную перерисовку.

### Параметры файла скрыты по умолчанию
Добавлена кнопка **«Параметры ▸»**.

- Правая панель больше не занимает место постоянно.
- При открытии показывает тип, размер, разрешение, длительность, FPS, кодек и даты файла.

### Видео без внутренних чёрных рамок
Видеоповерхность теперь сама подстраивает свой размер под фактическое соотношение сторон кадра.

- Видео не растягивается.
- Видео не обрезается.
- Внутри видеоповерхности не создаются letterbox/pillarbox-полосы.
- После нажатия **«↺ Вид» / «↻ Вид»** соотношение сторон пересчитывается заново, поэтому поворот 90° не ломает геометрию видео.
- Пустая область вокруг видео является обычным фоном интерфейса, а не частью видеокадра.

### Плеер перенесён под видео
Управление видео теперь центрировано непосредственно под областью просмотра.

Верхний ряд:
- timeline;
- текущее время / длительность.

Нижний ряд:
- −5 секунд;
- предыдущий кадр;
- Play/Pause;
- следующий кадр;
- +5 секунд;
- скорость.

### Скорость при запуске всегда 1×
V4 могла восстанавливать ранее сохранённые 0.5×. В V4.1 это отключено.

Каждый новый запуск программы начинается со скорости **1×**. Изменённая во время текущей сессии скорость продолжает работать до закрытия программы.

### Панель фоновых операций убрана
Фоновое копирование/перемещение продолжает работать, но нижняя панель прогресса больше не показывается.

Защита от закрытия программы во время незавершённой операции сохранена.

## Сохранённый функционал V4

- категории и горячие клавиши;
- несколько тегов;
- шаблоны переименования;
- переименование / копирование / перемещение;
- Undo;
- журнал;
- поиск точных дубликатов;
- поиск визуально похожих фото;
- предзагрузка фото и видео;
- правильная EXIF/metadata-ориентация;
- ручной поворот отображения;
- стрелки переключения файлов;
- полноэкранный режим;
- циклическое воспроизведение;
- фоновая очередь файловых операций.

## Запуск

Нужен Python 3.11+.

```bat
python -m pip install -r requirements_v4_1.txt
python media_categorizer_v4_1.py
```

Или запустите `run_v4_1.bat`.

## Сборка EXE

Запустите:

`build_v4_1_exe.bat`

После сборки файл будет находиться здесь:

`dist\MediaCategorizer4_1.exe`
